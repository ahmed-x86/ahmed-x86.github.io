About the Project

GRUB Fixer (V17 - The Intelligence Update) is the ultimate automated Bash script designed to repair the GRUB bootloader on both UEFI and Legacy BIOS systems. V17 introduces the Deep Scan Engine, which proactively maps your system layout (Root, Boot, Btrfs subvolumes) before the first prompt. By analyzing Kernel Command Line Parameters, it achieves 100% accuracy in environment detection (Live vs. Real Machine), offering a Unified One-Click Confirmation experience that eliminates complex manual steps.

🚀 New in V17: The script now features Proactive Deep Scan! It automatically finds and parses your /etc/fstab in the background, presenting a complete system map for a single "y/n" confirmation. No more manual partition guessing.

✨ New in V17 (The "Deep Scan" Update)

  • Kernel Cmdline Detection: Analyzes /proc/cmdline to instantly distinguish between Live ISOs (Archiso, Casper, etc.) and real installed systems.
  • Unified One-Click Prompt: Combines environment detection and layout confirmation into a single, clean summary for the user.
  • Deep Scan Engine: Stealthily scans and mounts partitions in read-only mode to locate fstab and resolve UUIDs/PARTUUIDs before user interaction.
  • Automatic efivarfs Repair: Improved In-Situ logic that ensures efivarfs is mounted, even if the rescue environment fails to do so.

⚙️ Evolution History (V16 - V12)

  • In-Situ (Local) Mode Detection (V16): Intelligently detects if run from the installed OS, bypassing the chroot environment to repair GRUB locally in seconds.
  • Dynamic UEFI 32-bit Detection (V15): Detects rare 32-bit UEFI architectures and automatically switches the GRUB target to i386-efi.
  • Dynamic Execution Timer (V14): Delivers gamer-style human status messages based on repair speed (e.g., "Wait, did I just fix that?! You didn't even get to sip your coffee! ☕").
  • OS Prober Integration (V13): Automatically enables GRUB_DISABLE_OS_PROBER=false to ensure Windows/other distros are detected.
  • Legacy BIOS & Smart Target Disk Extraction (V12): Full support for i386-pc with intelligent parent disk extraction (e.g., extracting /dev/sda from /dev/sda1).

🧠 Core "Power User" Features

  • Zero-Interaction FSTAB Parsing: Resolves UUID and PARTUUID tags instantly, mapping Btrfs subvolumes without manual input.
  • 3-Tier Fallback System: Gracefully falls back from Pro Mode (FSTAB) to Smart Auto-Detection, and finally to Manual Input.
  • Bulletproof Btrfs Loop: Interactive validation for complex subvolume hierarchies (@, @home, @log).
  • VM & NVRAM Rescue: Forced --removable flag usage for stubborn UEFI firmware and QEMU/KVM environments.

🛠️ Usage

Run the script directly via the one-liner or manual download.

Option 1: Quick One-Liner (Recommended)

curl -sL https://raw.githubusercontent.com/ahmed-x86/grub-fixer/main/grub-fixer.sh | sudo bash

Option 2: Manual Download & Execute

curl -O https://raw.githubusercontent.com/ahmed-x86/grub-fixer/main/grub-fixer.sh
chmod +x grub-fixer.sh
sudo ./grub-fixer.sh

  • Architecture: UEFI (x86_64/i386) or Legacy BIOS (i386-pc).
  • Privileges: Sudo/Root access required.
