About the Project

GRUB Fixer is a universal rescue tool designed to fix the "Minimal BASH-like line editing" error and other GRUB-related boot failures. It automates the complex process of identifying partitions, performing recursive bind mounts, and executing a chroot-based repair that works across almost all modern Linux distributions.

💡 Pro Tip: This script is perfect for users who accidentally broke their GRUB while dual-booting or performing system updates on any Linux distribution (Debian, Ubuntu, Arch, Fedora, openSUSE, and more).

✨ Key Features (V4)

  • Fail-Safe Execution: Uses set -e to immediately stop if a mount or command fails, preventing data corruption.
  • Automatic Cleanup: Scans /proc/mounts and cleans up /mnt before starting to avoid mount conflicts.
  • Smart OS Detection: Automatically pulls the distribution name from your system to set the correct bootloader-id.
  • Recursive Unmounting: Ensures all system directories are safely unlinked after the repair is complete.
  • Interactive Validation: Checks if the user-provided partitions actually exist before attempting to mount them.

🛠️ Quick Start (Live Environment)

Boot into your Live Linux ISO, open the terminal, and run the following command:

curl -sL https://raw.githubusercontent.com/ahmed-x86/grub-fixer/refs/heads/main/grub-fixer.sh | bash

📋 System Requirements

  • Boot Mode: UEFI (x86_64-efi).
  • Live ISO: Any Arch-based or Debian-based Live environment.
  • Privileges: Sudo access (included in script).
  • Connection: Internet access to download the script.
⚠️ Future Updates: Support for BIOS (Legacy), LUKS Encryption, and LVM partitions is currently in development for V5.
