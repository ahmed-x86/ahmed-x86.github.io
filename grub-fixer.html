About the Project

GRUB Fixer (V7 - Rescue Suite Edition) is an automated, bulletproof Bash script designed to repair the GRUB bootloader on UEFI Linux systems. This version evolves the project into a comprehensive recovery tool by allowing dynamic mounting of custom system partitions.

🚀 New in V7: The script now supports Custom Volumes. You can dynamically mount additional partitions (like /home, /var, or /opt) to ensure a perfect chroot environment for any recovery task.

✨ New in V7 (The Rescue Update)

  • Dynamic Custom Volumes: Added a loop-based UI to mount any number of additional partitions after core detection.
  • Automated Chroot Prep: Automatically creates mount points inside /mnt and binds essential kernel filesystems (/dev, /proc, etc.).
  • Rescue Versatility: High flexibility makes it useful for general system maintenance beyond just GRUB repair.

💎 Core Intelligence (V5-V6 Features)

  • Smart Auto-Detection: Scans for Root (ext4/btrfs/xfs) and EFI (vfat) partitions using lsblk and awk.
  • VM & NVRAM Rescue: Uses the --removable flag for Virtual Machines and stubborn UEFI firmwares.
  • Pipeline Ready: Fully supports curl | bash execution via /dev/tty input handling.
  • Bulletproof Safety: Immediate halt on errors (set -e) and recursive unmounting (umount -R) to keep your disks safe.

🛠️ Quick Start (Recommended)

Run the script directly from your terminal in any Live Linux environment:

curl -sL https://raw.githubusercontent.com/ahmed-x86/grub-fixer/main/grub-fixer.sh | bash
