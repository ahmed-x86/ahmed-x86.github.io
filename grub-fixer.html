About the Project

GRUB Fixer (V10 - Ultimate Btrfs & Mount Routing Edition) is an automated, bulletproof Bash script designed to repair the GRUB bootloader on UEFI Linux systems. This version is a major stability update that addresses specific installation quirks (like archinstall) and introduces a "Zero-Error" interactive flow for complex Btrfs layouts.

🚀 New in V10: The script now features Dynamic EFI Mount Logic (solving the missing kernel trap) and a Forced Validation Loop for bulletproof Btrfs subvolume mounting.

✨ New in V10 (The Bulletproof Update)

  • Dynamic EFI Mount Logic: Solves the common "missing kernel" trap by allowing users to choose the EFI mount path (/boot vs /boot/efi). This ensures grub-mkconfig always finds your vmlinuz images, especially on Archinstall setups.
  • Forced Validation Loop: The Btrfs subvolume mounting process is now bulletproof. It forces a strict y/n check, preventing the script from skipping crucial partitions due to accidental keyboard input or typos.
  • Improved Auto-Detection: Enhanced pre-scan logic to verify EFI partitions by looking for the actual /EFI directory structure before proposing it to the user.

🛡️ Features from V8 & V9

  • Dynamic Btrfs Subvolumes Support: Interactive loop to mount required subvolumes (e.g., @, @home, @log, @pkg) in the correct hierarchy before chrooting.
  • Smart Mount Routing: Automatically translates standard mount points to their chroot equivalents (e.g., inputting / correctly targets /mnt).
  • Smart EFI Validation: Actively verifies the /EFI directory by temporarily mounting candidates, preventing accidental installs on random USB drives.
  • Blackbox Logging System: Automatically captures and logs all stdout/stderr directly to /var/log/grub-fixer.log for a complete forensic troubleshooting trail.
  • Fail-Fast Root Check: Instantly halts execution cleanly if the script is not initiated with sudo.
  • Dynamic Custom Volumes: Mount additional partitions (e.g., external /home) dynamically during the repair process.
  • Intelligent Auto-Detection: Scans for Root candidates without mounting using lsblk and awk.
  • VM & NVRAM Rescue: Uses the --removable flag to guarantee booting on Virtual Machines (QEMU/KVM) and stubborn UEFI firmware that drop NVRAM variables.

🛠️ Quick Start (Recommended)

Run the script directly from your terminal in any Live Linux environment. (Note: sudo is required):

curl -sL https://raw.githubusercontent.com/ahmed-x86/grub-fixer/main/grub-fixer.sh | sudo bash
