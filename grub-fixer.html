About the Project

GRUB Fixer (V9 - Btrfs & Smart Detection Edition) is an automated, bulletproof Bash script designed to repair the GRUB bootloader on UEFI Linux systems. This version evolves the tool into a highly secure, intelligent Rescue Suite, now fully supporting complex filesystems like Btrfs out-of-the-box.

🚀 New in V9: The script now features Dynamic Btrfs Support (automatically detecting btrfs partitions and prompting for subvolumes) and Smart Mount Routing to prevent manual entry errors.

✨ New in V9 (The Btrfs Update)

  • Dynamic Btrfs Support: Automatically detects if the target Root partition is btrfs and launches an interactive loop to mount required subvolumes (e.g., @, @home).
  • Smart Mount Routing: Prevents user error by automatically translating standard mount points to their chroot equivalents (e.g., inputting / automatically mounts to /mnt).

💎 Smart & Core Features (V5-V8)

  • Smart EFI Validation: Actively verifies the /EFI directory by temporarily mounting candidates, preventing accidental installs on random USB drives.
  • Blackbox Logging System: Automatically captures and logs all stdout/stderr directly to /var/log/grub-fixer.log.
  • Fail-Fast Root Check: Instantly halts execution cleanly if the script is not initiated with sudo.
  • Dynamic Custom Volumes: Mount additional partitions (e.g., external /home) dynamically during the repair process.
  • Intelligent Auto-Detection: Scans for Root candidates without mounting using lsblk and awk.
  • VM & NVRAM Rescue: Uses the --removable flag for Virtual Machines and stubborn UEFI firmwares.

🛠️ Quick Start (Recommended)

Run the script directly from your terminal in any Live Linux environment. (Note: sudo is required):

curl -sL https://raw.githubusercontent.com/ahmed-x86/grub-fixer/main/grub-fixer.sh | sudo bash
