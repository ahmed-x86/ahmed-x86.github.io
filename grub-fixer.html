About the Project

GRUB Fixer (V13 - Ultimate Automation, Legacy BIOS & OS Prober Edition) is the definitive automated Bash script designed to repair the GRUB bootloader on both UEFI and Legacy BIOS Linux systems. This version introduces intelligent dual-boot detection via OS Prober, alongside the powerful Zero-Interaction "Pro Mode" that parses /etc/fstab to map and mount complex layouts (like Btrfs subvolumes) in seconds.

🚀 New in V13: The script now integrates OS Prober support! It automatically detects Windows and other Linux distributions in dual-boot setups, ensuring they reappear in your GRUB menu after the repair.

✨ New in V13 (The Dual-Boot Update)

  • OS Prober Integration: Automatically modifies /etc/default/grub to enable GRUB_DISABLE_OS_PROBER=false. This ensures that grub-mkconfig detects and adds Windows or other installed OSs to the boot menu automatically.

⚙️ Key Features in V12 (Universal Boot)

  • Legacy BIOS (i386-pc) Support: Automatically detects if your system lacks an EFI partition and dynamically switches the GRUB installation target, expanding compatibility to older machines.
  • Smart Target Disk Extraction: Uses lsblk -no PKNAME to intelligently extract the parent disk (e.g., /dev/sda) from your root partition, ensuring flawless installation on Legacy systems.

🛡️ Core Features (From V11 & V10)

  • Zero-Interaction FSTAB Parsing (Tier 1): Automatically scans devices to locate and parse your system's /etc/fstab. It resolves UUID and PARTUUID tags instantly, mapping out your exact system layout without manual input.
  • 3-Tier Fallback System: If fstab is missing or rejected, the script gracefully falls back to Smart Auto-Detection (Tier 2), and finally to fully Manual Input (Tier 3).
  • Dynamic EFI Mount Logic: Verifies and applies the correct EFI mount path (/boot vs /boot/efi), critical for Archinstall and CachyOS.
  • Bulletproof Btrfs Loop: An interactive loop ensures required subvolumes (e.g., @, @home, @log) are mounted in the correct hierarchy.
  • VM & NVRAM Rescue: Uses the --removable flag to guarantee booting on Virtual Machines and stubborn UEFI firmware.
  • Blackbox Logging System: Captures and logs all stdout/stderr directly to /var/log/grub-fixer.log.

🛠️ Quick Start (Recommended)

Run the script directly from your terminal in any Live Linux environment. (Note: sudo is required):

curl -sL https://raw.githubusercontent.com/ahmed-x86/grub-fixer/main/grub-fixer.sh | sudo bash
