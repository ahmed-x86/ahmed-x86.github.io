About the Project

GRUB Fixer is an automated, failsafe Bash script designed to repair the GRUB bootloader on UEFI Linux systems via a live chroot environment. It automates the tedious process of mounting, binding system directories, and reinstalling GRUB.

🎯 Target Audience: This project is designed for Linux beginners who may not know how to manually fix GRUB, as well as advanced users looking for a quick, automated solution to save valuable time.

💡 Pro Tip: This script is perfect for users who accidentally broke their GRUB while dual-booting or performing system updates on any Linux distribution (Debian, Ubuntu, Arch, Fedora, openSUSE, and more).

✨ New in V5 (Bulletproof Edition) & Core Features

  • VM & NVRAM Rescue (New): Added the --removable flag to grub-install to guarantee successful booting on Virtual Machines and stubborn UEFI firmware that drop NVRAM entries.
  • Input Collision Prevention (New): read commands now strictly fetch input from /dev/tty, eliminating terminal buffer conflicts and pipeline issues.
  • Safety First: Implemented set -e to stop execution immediately if any command fails, preventing system damage.
  • Automatic Cleanup & Exit: Detects and unmounts any existing processes on /mnt before starting, and automatically unmounts all filesystems recursively after a successful repair.
  • Improved Validation: Forces Root partition input and strictly verifies partition existence in /dev/ before proceeding.
  • Smart OS Detection: Automatically detects the distribution name from /etc/os-release to set the correct Bootloader ID.
  • Zero-Intervention Chroot: Executes all repair commands (grub-install and grub-mkconfig) automatically inside the chroot environment using EOF blocks.

🛠️ Quick Start (Live Environment)

Run the following commands directly from your terminal in any Live Linux environment (Arch, EndeavourOS, Ubuntu, Fedora, etc.):

curl -O https://raw.githubusercontent.com/ahmed-x86/grub-fixer/refs/heads/main/grub-fixer.sh
chmod +x grub-fixer.sh
sudo ./grub-fixer.sh

📋 System Requirements

  • Environment: Booted into a Live Linux ISO/USB.
  • Architecture: Target system must be UEFI (x86_64-efi).
  • Privileges: Sudo/Root access required.
  • Network: Active internet connection to fetch the script.
⚠️ Future Updates: Currently supports UEFI (x86_64-efi) only. Support for BIOS (Legacy), LUKS (Encryption), and LVM is planned for future releases.
