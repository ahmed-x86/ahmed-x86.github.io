About the Project

GRUB Fixer (V8 - Smart & Secure Edition) is an automated, bulletproof Bash script designed to repair the GRUB bootloader on UEFI Linux systems. This version evolves the tool into a highly secure, intelligent Rescue Suite, featuring active logging, strict validations, and smart partition verification.

🚀 New in V8: The script now features Smart EFI Validation (verifying the /EFI directory before mounting), a Blackbox Logging System for troubleshooting, and Fail-Fast Root Checks.

✨ New in V8 (The Smart & Secure Update)

  • Smart EFI Validation: Actively verifies the /EFI directory by temporarily mounting candidates, preventing accidental installs on random USB drives.
  • Blackbox Logging System: Automatically captures and logs all stdout/stderr directly to /var/log/grub-fixer.log.
  • Fail-Fast Root Check: Instantly halts execution cleanly if the script is not initiated with sudo, preventing messy, partial executions.

💎 Rescue & Core Features (V5-V7)

  • Dynamic Custom Volumes: Mount additional partitions (e.g., /home, /var) dynamically during the repair process for a perfect chroot environment.
  • Smart Auto-Detection: Scans for Root (ext4/btrfs/xfs) candidates without mounting using lsblk and awk.
  • VM & NVRAM Rescue: Uses the --removable flag for Virtual Machines and stubborn UEFI firmwares.
  • Pipeline Ready: Fully supports curl | bash execution via /dev/tty input handling.

🛠️ Quick Start (Recommended)

Run the script directly from your terminal in any Live Linux environment. (Note: sudo is required):

curl -sL https://raw.githubusercontent.com/ahmed-x86/grub-fixer/main/grub-fixer.sh | sudo bash
