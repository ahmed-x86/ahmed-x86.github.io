About

Welcome to my personal Hyprland configuration. Designed for aesthetics and performance using the Catppuccin color palette.

The Ecosystem Experience: Features a seamless, interactive automated setup to integrate your GitHub account (Rolling Contributions & Radar) and your Mobile device (via KDE Connect).

Installation

Online Install (Fastest & Fully Automated)

bash -c "$(curl -fsSL https://raw.githubusercontent.com/ahmed-x86/hyprland_dotfiles/refs/heads/main/online-install.sh)"

Offline Install (Manual)

git clone https://github.com/ahmed-x86/hyprland_dotfiles
cd hyprland_dotfiles
chmod +x *
./main.sh
